# Техническое задание

## 1. Наименование проекта
Интернет-магазин кондитерских изделий **MadeByTasya**.

## 2. Слоган
«Её руки, мой код, ваш вкус».

## 3. Цель
Разработать учебное веб-приложение в рамках лабораторных работ по дисциплине «Internet технологии».

## 4. Функциональные возможности
- Просмотр каталога товаров (торты, пирожные, штрудель, выпечка).
- Просмотр страницы товара с описанием, составом и ценой.
- Добавление товара в корзину.
- Оформление заказа с выбором доставки и оплаты.
- Отслеживание статуса заказа по номеру.
- Получение рекомендаций и новинок через API.
- Авторизация и регистрация пользователя.
- Просмотр контактной информации магазина.

## 5. Структура страниц
1. **Главная** (`index.html`)
2. **Карточка товара** (`product.html`)
3. **Контакты** (`contacts.html`)

## 6. Требования к интерфейсу
- Единая шапка с контекстным меню и гиперссылками.
- Наличие собственного логотипа.
- Адаптивность под мобильные и десктопные экраны.
- Кроссбраузерная верстка.

## 7. Используемые технологии
- HTML5
- CSS3 (+ подключение Tailwind CSS через CDN)
- JavaScript (динамические формы, API, переходы)
- SQL (структура БД из 2 таблиц)

## 8. Этапы выполнения
- **ЛР1**: статическая верстка и контент.
- **ЛР2**: динамика, формы, API, авторизация.
- **ЛР3**: проектирование БД и хранение пользовательских данных.
